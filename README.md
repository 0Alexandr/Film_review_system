# Название проекта: КиноОтзыв

## Назначение
Приложение представляет собой платформу для обмена мнениями о кинематографе. Оно решает задачу **сбора, структурирования и поиска пользовательских рецензий и оценок** к фильмам, помогая людям находить качественное кино для просмотра на основе честных рейтингов.

## Целевая аудитория
- **Любители кино (киноманы):** пользователи, которые хотят вести учет просмотренного, ставить оценки и делиться развернутыми отзывами.
- **Обычные зрители:** люди, ищущие рекомендации и оценки перед просмотром фильма, чтобы сэкономить время.

## Предметная область
Сфера развлечений, социальные платформы и агрегаторы контента. Проект охватывает процессы каталогизации кинопроизведений, механики выставления пользовательских рейтингов и ведения текстовых блогов/рецензий.

## Основные сущности
- **Фильм:** содержит информацию о кинокартине (название, год выпуска, жанр, режиссер, средний рейтинг).
- **Пользователь:** профиль человека в системе (имя/никнейм, дата регистрации, список оставленных отзывов).
- **Оценка:** числовой балл, выставляемый пользователем фильму по определенной шкале (от 1 до 10).
- **Отзыв:** текстовая рецензия пользователя на конкретный фильм, привязанная к дате публикации и содержащая вердикт (рекомендует/не рекомендует).

## Основные функции
- **Управление каталогом:** добавление, просмотр и поиск фильмов по названиям и жанрам.
- **Оценка и рецензирование:** возможность для пользователя поставить оценку фильму и написать текстовый отзыв.
- **Расчет рейтинга:** автоматическое вычисление среднего балла фильма на основе всех выставленных оценок.
- **Фильтрация контента:** просмотр лучших фильмов по рейтингу или последних добавленных отзывов.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация полноценной системы пользователей (регистрация и авторизация);
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
