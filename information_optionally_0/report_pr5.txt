Тема проекта: система отзывов о фильмах "КиноОтзыв".

Что сделано:
- создан Django-проект filmreviews;
- добавлены приложения homepage, catalog и reviews;
- реализована главная страница со статистикой, лучшими фильмами и отзывами;
- реализован каталог фильмов по адресу /movies/;
- реализована страница фильма по адресу /movies/<id>/;
- реализован список отзывов по адресу /reviews/;
- реализована страница отзыва по адресу /reviews/<id>/;
- для несуществующих фильмов и отзывов возвращается код 404;
- подключена пользовательская страница 404;
- данные страниц загружаются из JSON-файлов проекта через load_system();
- в services.py добавлены функции find_movie_by_id() и find_review_by_id();
- добавлены тесты Django-страниц и тесты новых функций.

Проверка:
- python manage.py check
- python manage.py test
- python -m pytest
- python -m flake8 .

Примечание:
Проект Django добавлен рядом с кодом предыдущей практической работы.
Код ПР3 не удалялся и используется веб-страницами как источник данных.
